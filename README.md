# مدرستن (Madrastan)

نظام سحابي لإدارة المدارس الخاصة (أول مدرسة عليه: **Epsilon**)، مبني بـ React و Vite، بواجهة عربية كاملة (من اليمين لليسار) وخط Cairo.

الموقع: https://ahmedtalb872.github.io/Medrasti/

## التشغيل

```bash
npm install
npm run dev
```

## المميزات

- **لوحة التحكم**: الطلاب، المعلمون، المحصَّل، المتبقي، نسبة التحصيل، آخر المدفوعات، والطلاب المتأخرون
- **الطلاب**: بحث وتصفية حسب الفصل، إضافة وتعديل وحذف، صورة الطالب، الخصم، وملف خاص بكل طالب
- **بطاقة الطالب**: بطاقة خاصة لكل طالب بالمقاس القياسي (85.6 × 54 مم) فيها الصورة والرقم ورمز QR، وتحميلها PDF فرديًا أو كلها معًا (8 بطاقات في صفحة A4)
- **المالية**: رسوم سنوية لكل فصل، خصومات، تقسيط شهري، حالة كل قسط (مدفوع، جزئي، متأخر، قادم)، وتسجيل الدفعات
- **مستندات PDF**:
  - بطاقة الدفع (A4): بيانات الطالب، ملخص الرسوم، جدول الأقساط، وسجل المدفوعات
  - إيصال الدفع (A5): يُحمَّل تلقائيًا بعد تسجيل كل دفعة
  - الفاتورة (A5): الأقساط المستحقة على الطالب الآن، وتُرسَل لولي الأمر على واتساب (ملف PDF من الهاتف، أو رسالة نصية مباشرة لرقمه)
- **المصاريف**: تسجيل مصاريف المدرسة (رواتب، إيجار، كهرباء…) حسب الفئة والشهر والفرع، مع صافي الشهر (المحصَّل ناقص المصاريف) وتصدير CSV
- **الفروع**: مدرسة واحدة بعدة فروع. كل قسم وطالب يتبع فرعًا، والمالك يرى كل الفروع مجمّعة أو كل فرع وحده، وموظف الفرع يرى فرعه فقط
- **الفصول والمعلمون** وإعدادات المدرسة (الاسم، العنوان، العملة، العام الدراسي، عدد الأقساط)

## قاعدة البيانات (عدة مدارس)

النظام يعمل بوضعين:

- **محلي**: بدون إعداد، والبيانات في متصفح المستخدم (للتجربة).
- **سحابي**: قاعدة بيانات واحدة على Supabase تجمع كل المدارس. كل مدرسة لها حساباتها، ولا يرى أحد بيانات مدرسة ليس عضوًا فيها (الحماية مفروضة داخل قاعدة البيانات بسياسات RLS).

### خطوات التفعيل

1. أنشئ مشروعًا على [supabase.com](https://supabase.com).
2. افتح **SQL Editor** وشغّل الملفات بالترتيب، كل ملف كاملًا ثم **Run**:
   1. `supabase/migrations/0001_schools.sql`
   2. `supabase/migrations/0002_branches.sql`
   3. `supabase/migrations/0003_expenses.sql`
3. من **Authentication → URL Configuration** ضع رابط الموقع في **Site URL** و **Redirect URLs**:
   `https://ahmedtalb872.github.io/Medrasti/`
4. من **Project Settings → API** انسخ **Project URL** و **anon public key**.
5. في GitHub: **Settings → Secrets and variables → Actions → Variables** أضف:
   - `SUPABASE_URL` = رابط المشروع
   - `SUPABASE_ANON_KEY` = المفتاح العام
6. شغّل النشر من جديد (**Actions → Deploy to GitHub Pages → Run workflow**).

للتشغيل على جهازك بوضع سحابي، أنشئ ملف `.env.local` فيه:

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

بعدها يفتح النظام بصفحة تسجيل الدخول. أول مرة: أنشئ حسابًا، ثم أضف المدرسة. إذا كانت في المتصفح بيانات قديمة يظهر خيار لنقلها إلى المدرسة الجديدة.
