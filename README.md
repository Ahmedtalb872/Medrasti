# مدرستي (Medrasti)

نظام إدارة مدارس مبني بـ React و Vite، بواجهة عربية كاملة (من اليمين لليسار) وخط IBM Plex Sans Arabic.

## التشغيل

```bash
npm install
npm run dev
```

## المميزات

- **لوحة التحكم**: الطلاب، المعلمون، المحصَّل، المتبقي، نسبة التحصيل، آخر المدفوعات، والطلاب المتأخرون
- **الطلاب**: بحث وتصفية حسب الفصل، إضافة وتعديل وحذف، صورة الطالب، الخصم، وملف خاص بكل طالب
- **بطاقة الطالب**: بطاقة خاصة لكل طالب بالمقاس القياسي (85.6 × 54 مم) فيها الصورة والرقم ورمز QR، وتحميلها PDF فرديًا أو كلها معًا (8 بطاقات في صفحة A4)
- **المالية**: رسوم سنوية لكل فصل، خصومات، تقسيط شهري، حالة كل قسط (مدفوع، جزئي، متأخر، قادم)، وتسجيل الدفعات
- **مستندات PDF**:
  - بطاقة الدفع (A4): بيانات الطالب، ملخص الرسوم، جدول الأقساط، وسجل المدفوعات
  - إيصال الدفع (A5): يُحمَّل تلقائيًا بعد تسجيل كل دفعة
- **الفصول والمعلمون** وإعدادات المدرسة (الاسم، العنوان، العملة، العام الدراسي، عدد الأقساط)

## ملاحظات

- البيانات تُحفظ حاليًا في متصفح المستخدم (localStorage). الخطوة القادمة: ربط قاعدة بيانات على خادم.
- البيانات الأولية تجريبية، ويمكن إعادتها من صفحة الإعدادات.
