# مدرستي (Medrasti)

نظام إدارة مدارس مبني بـ React و Vite، بواجهة عربية (من اليمين لليسار).

## التشغيل

```bash
npm install
npm run dev
```

## الصفحات الحالية

- **لوحة التحكم**: إحصائيات سريعة (عدد الطلاب، المعلمين، الفصول)
- **الطلاب**: عرض، بحث، إضافة وحذف
- **المعلمون**: قائمة المعلمين
- **الفصول**: الفصول مع المعلم المسؤول وعدد الطلاب

البيانات حاليًا تجريبية في `src/data/mock.js` إلى أن يتم ربط قاعدة بيانات.
